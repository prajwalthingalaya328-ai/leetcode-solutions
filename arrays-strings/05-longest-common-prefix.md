# Problem: Longest Common Prefix (Easy)

Link: https://leetcode.com/problems/longest-common-prefix/

## Approach

I compare the characters of the first string with the other strings one by one. The common prefix length is reduced whenever a mismatch is found.

## Complexity

Time: O(n × m)
Space: O(1)

## Notes

Tested the program with two test cases. The first has "fl" as the common prefix and the second has no common prefix.
