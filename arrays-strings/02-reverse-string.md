# Problem: Reverse a String (Easy)

Link: https://leetcode.com/problems/reverse-string/

## Approach

I used a loop to traverse the string from the last character to the first character. Each character is printed in reverse order to reverse the string.

## Complexity

Time: O(n)
Space: O(1)

## Notes

Tested the program with two test cases. The first is a normal string and the second is a single-character edge case.
